# תיקון ניסוח להודעות של בוטים בדיסקורד

`humanize.py` עורך את הניסוח של הודעה רגע לפני שהבוט שולח אותה. זו עריכה קלה, לא שכתוב: התוכן, המספרים, השפה, הטון והעיצוב של דיסקורד (תיוגים, אימוג'י, markdown) נשארים כמו שהם. משתנה רק הניסוח, כדי שיישמע טבעי.

אם משהו נכשל (אין רשת, הגבלת קצב, תשובה חסרה), נשלחת ההודעה המקורית. הבוט אף פעם לא נתקע בגלל השלב הזה.

## התקנה

1. מעתיקים את `humanize.py` לתיקייה של הבוט.
2. `pip install anthropic`
3. מוודאים ש-`ANTHROPIC_API_KEY` מוגדר בסביבה של הבוט.

## חיבור לבוט (discord.py)

בכל מקום שבו הבוט שולח טקסט, עוטפים אותו ב-`humanize`:

```python
from humanize import humanize

# לפני
await channel.send(text)

# אחרי
await channel.send(await humanize(text))
```

אותו דבר עם `message.reply(...)`, `ctx.send(...)` וכו'. אם יש לבוט פונקציה אחת מרכזית שממנה יוצאות כל ההודעות, מספיק לעטוף רק אותה.

## הגדרות

- `MIN_LENGTH` (ברירת מחדל 40 תווים): הודעות קצרות יותר נשלחות בלי עריכה, כמו "✅ נכנסנו" או מחיר בודד. חוסך קריאות ל-API.
- `HUMANIZER_MODEL` (משתנה סביבה): המודל שעושה את העריכה. ברירת המחדל היא `claude-opus-5-5`.
- כל הודעה שעוברת עריכה היא קריאה אחת ל-API, ומוסיפה בערך שנייה או שתיים לפני שההודעה מופיעה.
